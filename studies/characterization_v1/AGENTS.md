# Characterization study boundaries

`frozen_run/` is immutable source, including its vendored numerical code and configuration. Do not edit it to fit returned outcomes. New scientific revisions require a new study identity, fresh output directory and explicit protocol amendment.

Keep original returned archives and receipts under ignored `imports/`. Do not publish raw coordinates, private inputs, credentials or host paths. Post-run tools must not launch models, overwrite an import or automatically promote results into the manuscript.

Reconstruct what the compact export supports. Explicitly report missing full hidden states/forward verification and unsupported optimizer-dependent refits. Integrity, engineering correctness and scientific interpretation are separate decisions.

# Completed template-centering diagnostic: portable reproduction

The saved diagnosis compares the original complete test bank, removal of each
template variant's state mean while retaining the original whitening, and
removal of the same mean followed by fresh whitening. All 48 C7/D4 cells and
all 120 C7 / three D4 images per cell remain included. The score is `C16/16`;
for the fixed-whitening residual it is not the fraction of residual energy.
These are finite-bank spectral-budget rankings, not rankings of exact optimum
risks, population inference, or new predictive-fit experiments.

The original 2026-11-10 CSVs, summaries and receipts are in
`results/template_centering_v1/{rewhitened,three_way}/`. They were copied without
changing their bytes. Packaging did not execute their mathematical workers.

## Source preservation and portability

`historical_sources/` preserves both original scientific scripts byte for byte.
Do not execute these historical files directly: they retain their old relative
input/output layout. The two top-level `diagnose_*.py` files are publication
derivatives that change only input-reader imports, path bindings and output
locations. `PUBLICATION_DERIVATIVES.json` records each exact replacement and both
source hashes. `run.py verify` reverses the replacements and requires exact
equality to the original scripts; no mathematical statement or tolerance changes.

The mathematical dependency is the existing, unchanged
`studies/spectral_dimension_sensitivity_v1/core/` tree. Its vendored kernel hash
is `e91c735890bdf888a25db07d1207d3f44cdce8ce1bf6ee7e2efcf7bf40a50f41`, matching the
two historical diagnostic receipts. `historical_protocol.json` preserves the
protocol object bound by the original input manifest. The public adapter reads
original saved coordinate objects and the explicitly documented projection of
historical anchors in `data/retained_coordinates/`; it needs no private path,
archive, credential, model download or model forward.

## Standard-library verification

```sh
python3 -B studies/template_centering_v1/run.py verify
```

This checks source/result/data hashes and complete test row/state bindings.
It does not import NumPy or execute whitening, eigendecomposition, fitting,
simulation, bootstrap, image enumeration or matrix analysis.

## Explicit numerical reproduction

Use NumPy 2.2.6 (the archived numerical dependency). Set BLAS thread variables
according to the chosen local environment before starting, and use fresh output
directories. Neither command loads a language model or refits PCA.

```sh
python3 -B studies/template_centering_v1/run.py run \
  --stage rewhitened --output work/centering-rewhitened-fresh \
  --execute-offline-analysis

python3 -B studies/template_centering_v1/run.py run \
  --stage fixed --output work/centering-three-way-fresh \
  --execute-offline-analysis
```

The first command reproduces the original/rewhitened two-treatment results.
The second preserves the historical fixed-metric calculation: it reads the
authenticated **saved** two-treatment CSVs, adds the fixed-metric branch, and
writes the three-treatment results. It does not silently substitute an arbitrary
new first-stage output. Numerical reproduction is an explicit separate activity;
the included results are the frozen prior execution, not outputs generated by
assembling this release. Original expected rank counts are C7 `7 -> 15 -> 18`
and D4 `16 -> 0 -> 0` (original, centered/fixed metric, centered/rewhitened).

The data, saved results, this entire study directory, and the dependency `core/`
form the anonymous execution closure. No parent-layer archive reader or private
research directory is needed. The full GitHub delivery additionally retains S3
coordinate objects; the anonymous allowlist selects only necessary C7/D4 data.

## Input/export limitations

See `data/retained_coordinates/README.md`. The export includes saved q=16
coordinates and PCA, not full hidden activations or the discarded state variation.
It cannot establish original model execution, restore missing historical lexical
outputs, or enable unrelated neural/interface/potential refits from coordinates
alone. `tools/export_retained.py` is the standard-library packaging tool for an
owner with access to the authenticated original archives; it never runs these
numerical workers.

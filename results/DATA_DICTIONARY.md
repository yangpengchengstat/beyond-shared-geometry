# Evidence fields and estimands

This dictionary describes the included tables. Blank cells represent inapplicable metrics, not zeros. Values are dimensionless normalized errors except token logits, probabilities, log probabilities and proportions. Lower error is better. Original names are retained so that fields can be joined to frozen historical tables and the source implementation.

## Identifiers and hierarchy

- `model`, `model_A`, `model_B`: immutable model repository identifiers for one model or an ordered cross-model pair. Exact requested revisions are in the included configurations. `model_key`, `model_key_A`, `model_key_B` are short aliases; `model_family` is Llama or Qwen.
- `group`: C7, D4, or ALL for a declared cross-group aggregate. C7 acts on seven weekday labels. D4 acts faithfully on the four square-corner labels NW, NE, SE, SW. These are controlled state vocabularies, reused across templates.
- `layer`: transformer block-output index; `layer_A`, `layer_B` identify each paired model's block. Embedding layer zero is a distinct representation location, not a transformer block.
- `depth_slot`: one of the four fixed normalized-depth targets 0.20, 0.40, 0.60, 0.80. `realized_depth` is the actual block index divided by model block count. AFS-D embedding is represented by zero with `representation_location=embedding`.
- `latent_dim`: PCA dimension. FULL and AFS ABC primary data use 16. Rank-aware AFS D uses C7=6 and D4=3 at both locations. `pca_variance` is the fraction of training variance retained.
- `split_seed`: one of 101, 303, 909, 2701, 4243, defining a deterministic 28/6/6 partition of 40 templates. `template_id`: a template identifier, not an independent model. Each template includes every state of its orbit. Splits/templates recur across depths/models; the original nested-bootstrap design is not a crossed-cluster analysis.
- `optimization_seed`: technical deterministic fit seed 42 where recorded; not a scientific replication axis. `random_baseline_seed`: random orthogonal realization, with five controls. `scramble_seed`: one of five correspondence-randomization controls; not an independent model.
- `method`: estimator or control name; `independent_ridge` fits an independent linear map for each element; `group_consistent_joint` jointly regularizes the group laws. `generator_composed` uses only the minimal learned generators; `direct_ridge` fits the composite element separately; `identity`, `matched_random_generator`, `matched_wrong_word`, and `random_orthogonal` are the indicated controls. `learned_operator` is the causal intervention from the Joint fit; `source_conditioned_additive` is a separate behavior comparator. Additive-field tables instead use `additive`, `ridge`, `joint`.
- `data_split`: test, validation, or operator-only diagnostics, where present. Reporting derivatives explicitly select test; that omitted constant is declared in the registry. `evaluation_role`, `intervention`: the original causal or generator evaluation condition. `comparison_type`: within-family or cross-family model pairing.
- `target_element`, `word`, `word_length`, `step`: intended group element and externally composed generator word/length/power. D4 uses row vectors: multiplying `R(g2) R(g1)` applies `g2` first and then `g1`, targeting `g1 compose g2`. `generator_generalization_gap` is composed-generator error minus direct Ridge error for the same held-out composite.
- `scramble_variant`: `real` (unaltered training), `train_only_state_relabel` (independent coherent relabeling per training template), or `template_independent_target_scramble` (independent target correspondence permutation per template/nonidentity element). Validation/test correspondences remain true.
- `representation_location`: embedding or internal. `source_run`: the original run identifier retained by AFS-D's rank-matched analysis. `unit_type`: template-level error or one operator-level split observation; operator statistics are not repeated as independent template observations.

## Structural and generator metrics

Let Z contain the PCA latent states from one held-out template, and Z_g their true transformed endpoints. The executed data-defect function is `D(A,B)=mean_i[||a_i-b_i||_2^2/(||b_i||_2^2+eps)]`, with eps=1e-12. `E_eq` is the mean over nonidentity elements of `D(Z R(g),Z_g)`. `E_gen_eq` uses an externally composed generator word in place of the direct operator and is evaluated only on never-independently-fitted elements in the primary generator subset. `E_word` is the canonical runner's word-endpoint prediction error. The executed mean-of-row-ratios differs from a ratio of summed Frobenius errors printed in some historical protocols; the executed metric is documented here and used by all included observations.

`E_hom_data` compares `Z R(g2)R(g1)` with `Z R(g1 compose g2)` over every ordered element pair; `E_hom_op` compares the corresponding operators. These are consistency diagnostics with fitted operators as targets. `E_comp_data` and `E_comp_op` summarize the nonidentity composition subset, rather than providing independently unseen endpoint labels. D4 `E_rel_data` averages the three defining-relation data defects and additionally records separate `E_rel_r4_data`, `E_rel_s2_data`, `E_rel_srs_r_inverse_data` components. C7 `E_rel_data` instead averages three component means: the r^7 identity cycle; generator-power versus directly fitted operator consistency for k=0,...,6; and inverse consistency for k=1,...,6. `E_rel_op` averages the registered defining-relation operator defects. `E_inverse_data` and `E_inverse_op` measure composition with the registered inverse against identity. The implementation distinguishes squared data-supported defects from unsquared relative operator Frobenius defects `||A-B||_F/(||B||_F+eps)`; those scales must not be merged. Exact metric functions are in `src/bsg/metrics/`.

Small errors establish recoverable linear action/consistency in this controlled state vocabulary. Arbitrary stable affine-independent category codes can also admit exact permutation representations. Metrics and AFS controls therefore do not uniquely establish a native internal algebraic computation.

## Confidence intervals and permutation summaries

- `analysis`, `contrast`: registered estimate or signed paired comparison. `metric` is the measured quantity. Causal tables overload `method` with the evaluation role (e.g. transformation); D4 order rows use learned_operator. `model=ALL` or `ALL_MODELS` is a declared fixed-panel aggregate, not a sampled model population.
- `mean`, `learned_estimate`, `baseline_estimate`: original estimate and paired component estimates. `ci_low`, `ci_high`: archived two-sided 95% percentile bootstrap bounds; `ci_mid` is the bootstrap median where supplied. The asset builder never recomputes these intervals. `n_boot`/`bootstrap_reps` and `bootstrap_seed` record bootstrap settings, usually 5,000 and 314159.
- `n_pairs`, `n_observations`, `n_models`, `n_depths`, `n_splits`, `n_templates`, `n_random_seeds`, `cluster_columns`: archived sample counts and recursively resampled axes. Counts of templates can be 23 unique test IDs across five overlapping splits; that is distinct from six test templates per split. Control randomness and optimizer labels must not be turned into independent scientific replicates.
- AFS-B `true_relation_defect`, `null_mean`, `null_median`, `null_q025`, `null_q975`: defect under true registration and the conditional distribution from 5,000 with-replacement identity-preserving nonautomorphic operator relabelings. `true_percentile=100*mean(null<=true)` and `empirical_p=(1+count(null<=true))/(N+1)`. `standardized_null_separation=(null_mean-true)/null_sd`. `n_permutations` counts draws, not distinct permutations. C7 has only 714 admissible nonautomorphisms. Automorphisms preserve the action registration and are excluded. This distribution is conditional on fixed operators/coordinates.
- AFS-D `scope`: one fixed depth or `fixed_depth_average`; `embedding_estimate`, `internal_estimate`, `mean_difference` are paired internal-minus-embedding errors. Positive differences favor embedding. `fraction_depths_internal_better` counts the fraction of the four depth means with negative differences. `value` and `mean_value` are observations or descriptive averages identified by `metric` and `unit_type`.

## Behavioral metrics

`target_logit_change` and `target_probability_change` are edited-minus-unedited target-token scores. `top1_success` is the proportion with the intended first continuation token ranked first, not unconstrained task completion. `target_sequence_log_probability` is available only when the complete intended continuation is a single token under the archived scoring convention. `min`, `max`, `count` in the included continuation-count derivative summarize the original `target_sequence_token_count`; every archived count was one, but raw token IDs/source-span token counts are not present in that table. `n_source_rows` counts rows collapsed into a descriptive model/group/method mean. Random controls have five times the rows of one deterministic method and are averaged within method.

The strong FULL comparator estimates `v_(g,s)=mean_train_t[h(g s,t)-h(s,t)]` and applies it to the held-out source state. It is source- and transformation-conditioned. `relation_final_logit_distance` compares an externally precomposed word edit with a direct inverse-operator edit; D4 correct-minus-wrong is negative when the correct word is closer. It does not demonstrate unedited sequential execution of those generators inside the model. `interpretation` is an archived annotation, not an independent result.

## Global additive-field aggregates

`metric_family`: direct, c7_composition, d4_sr, d4_rs, d4_srs, or a descriptive order-separation diagnostic. `component` identifies element/power/word or order comparison. `primary`/`diagnostic` mark the prespecified role. `value` is the mean normalized prediction error across the source states/test templates in a cell, or the named separation diagnostic. `per_seed_aggregates.csv` averages the fixed model/depth panel, balancing groups for direct prediction and averaging D4 component families for d4_combined; `per_seed_contrasts.csv` subtracts each comparator from additive. The intervals bootstrap only the five paired split-seed values.

The global estimator `v_g=mean_train_(s,t)[z(g s,t)-z(s,t)]` is a mean over complete finite orbits. Each g permutes the same set of state vectors within a template, so every vector is exactly zero in real arithmetic. It therefore predicts identity and fails nontrivial state transformations by construction; this is not evidence excluding state-conditioned or nonlinear fields. The archived outcome classification is B, not the clean direct-matched compositional-failure outcome A.

## Embedding-rank diagnostics and cross-model values

`rows`, `train_rows`: total and training matrix rows. `unique_embedding_vectors`, `raw_matrix_rank`, `centered_training_rank`, `max_admissible_pca_dim`, `frozen_group_latent_dim`, `expected_centered_rank`, `rank_status`, `duplicate_accounting`: measured uniqueness/ranks, the declared matched dimension, pass marker and exact-row duplicate method. C7 has seven unique embedding vectors and centered rank six; D4 has four and rank three. Repeated template labels do not create new embedding vectors.

In `cross_model_metrics.csv`, `metric` names fitted/procrustes/random/shuffled commutation error, Procrustes reconstruction error, linear CKA, or a paired commutation contrast; `value` stores that named quantity. Intertwiners fit and score the same element set and have no enforced invertibility/full-rank requirement. The shuffled-label metric reuses the fitted map. These metrics are secondary in-sample compatibility diagnostics, not out-of-sample transport or full-representation isomorphism.

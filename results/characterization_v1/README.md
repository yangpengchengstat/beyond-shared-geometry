# Reviewed descriptive characterization aggregates

These small tables are manually curated from the completed characterization-v1 return after separate integrity, coordinate and uncertainty audits. The original `paper_eligible=false` and inference flags remain unchanged. The current user requested a project/manuscript revision; this is a documented descriptive integration, not an automatic promotion or a powered confirmation.

`reviewed_summary.json` records the original archive identity, member patterns, estimands, scope and derived-file hashes. Original coordinates and receipts remain private. `prediction_summary.csv` contains q16 normalized losses, not answer accuracy. The decoded unseen-composite extension is an explicitly additional-information audit control using construction labels and an exact action table; it is not primitive-pair-only confirmation. The manuscript's primary characterization table uses the frozen all-element and generator-kernel comparisons and the existing direct decoded-centroid control.

The six models and four readouts are fixed conditions. The per-model table exposes heterogeneous effects. Coordinate storage excludes common PCA/runtime overhead; identity-pruned and original counts are both supplied. Descriptive sensitivity intervals are not significance or equivalence decisions.

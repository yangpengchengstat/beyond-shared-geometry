Evidence decision after implementation revision 0.4.9
Date: 29 October 2026
Status: implementation preparation; no new real-bank analysis or experiment

DECISION
A new model experiment is not required to state the current analytical and
fixed-panel descriptive findings accurately. For strengthening the paper, the
highest-priority next step is one bounded analysis of already saved coordinates.
The new implementation prepares that step; its existence and software tests do
not resolve the missing empirical link. The current paper still reports no LLM
gamma values, no exact-action witness and no independent-context certification.

The fixed primary analysis remains the 0.4.8 panel and metric, as implemented by
studies/spectral_finite_bank_v1/. This revision does not authorize automatically
running the real-coordinate analysis. Its prepare/analyze separation, source
identity and fresh output location are intended to make a later execution
explicit and reviewable. Follow that study's README for commands and safeguards.

NEXT STEP: EXISTING-COORDINATE ANALYSIS
1. Freeze the implementation/protocol identity and verify the selected private
   input archive, member hashes, model/layer/PCA provenance and exact test rows.
2. Compute all 48 planned C7/D4 cells under the same fixed r=16, full uniform
   action/state grid and empirical second-moment metric. Preserve failures;
   never replace them by favorable ranks, layers, registrations or subsets.
3. Review gamma, the risk interval, ordinary spectrum, type correction, energy
   allocation and numerical residuals jointly. Report a near-zero correction
   or a failure as such; neither requires restarting the experiment pipeline.
4. Integrate an actual summary table or figure only after output validation.
   Decide prominence by explanatory content, not whether the result is positive.

This uses existing compact coordinates and no model forward pass. It does not
require RunPod, model downloads, old calibration or the full historical suite.
If provenance or numerical eligibility fails, retain a not_evaluable outcome;
do not automatically regenerate activations. No runtime estimate is promised
before execution and numerical checks.

WHAT THE ANALYSIS CAN CHANGE
An informative finite-bank bound would connect the theory to measured frozen
representations and strengthen the paper's empirical coherence. If the ordinary
and type-constrained budgets are nearly identical, that limits the demonstrated
value of the type correction on this panel, while leaving the analytical
separation and theorem valid. A large gamma establishes compatibility with a
low-risk exact action in this bank; it does not exclude stable category coding
or establish native causal use. An uninformative bound should not be recast as
a semantic-identification discovery.

WHETHER TO ADD AN EXPERIMENT AFTERWARD
- Retain only fixed-panel characterization: no new experiment is logically
  required. Keep broader generalization as an open question.
- Make robustness across independently constructed language contexts a central
  contribution: one targeted independent-context evaluation is needed. Existing
  splits and retrospective spectral summaries cannot provide that evidence.
- Claim a practical exact-action predictor: first construct and verify a witness,
  then compare frozen predictors on a separately specified test distribution.
  This is a different task from merely computing gamma.
- Claim native causal computation: a new design establishing clean competence,
  intervention fidelity and the relevant necessity/sufficiency distinction is
  required. This is not the recommended next extension for the current paper.

PREFERRED TARGETED FOLLOW-UP, IF GENERALIZATION IS PURSUED
Freeze independently authored context families and complete state blocks before
seeing model outputs; paired variants are needed for context-difference transport.
Do not treat paraphrases of the original templates as independent construction.
Use the existing model revisions and fixed readouts, and preferably frozen fitted
predictors. If new fitting is necessary, separate its training bank from the final
independent test bank in advance. Select one primary comparison, with matched
inputs/targets and explicit information and capacity conditions. Dedicated
context-difference fitting versus coordinate-fitted operators on the same paired
differences is a suitable candidate, conditional on the retained scientific claim.

Prespecify a practically meaningful contrast, context-family-level uncertainty,
and any multiplicity policy. Choose size from precision/power for that contrast,
not from model/layer counts or the approximately 17,000-context precondition of
the conservative Theorem 8 formula. Do not select layers, budgets or registrations
using final test outcomes. This document commits neither a new sample size nor
a GPU run.

STOPPING AND PRESERVATION
Do not broaden models, groups, dimensions or simulations simply to obtain a
positive result. The original FULL/AFS measurements, calibration failures, rank
failure, native scientific stops and old manuscripts remain evidence. Revision
0.4.9 improves implementation and interpretation; it does not convert those
records into passes or establish a numerical acceptance probability.

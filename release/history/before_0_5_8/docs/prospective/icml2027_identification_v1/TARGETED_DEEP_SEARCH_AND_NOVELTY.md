# Beyond Shared Geometry: targeted deep search and a decisive next study

Evidence checked on 16 October 2026. This is an English research-planning document. All experiments below are proposed, unless explicitly described as archived findings or findings reported by another paper. No new model experiment was run, no result was invented, and no released manuscript, frozen run, or published repository was changed. Here, synthetic, sham, and negative-control experiments mean deliberately constructed tests with disclosed ground truth; they never mean fabricated empirical findings.

## 1. The result worth pursuing

The most defensible next study asks **when fitted finite-group actions identify useful representational structure beyond category transport, and when that structure predicts interventions on a model's own computation**. Recovering matrices, obtaining small relation errors, adding more calendar concepts, and producing successful state patches are already established research directions. A stronger submission would connect a carefully calibrated structural diagnostic to prospective, held-out causal predictions, with convincing cases where simpler explanations succeed and where they fail.

A concrete target claim is:

> Across independently held-out task and lexical families, a frozen procedure distinguishes semantic action recovery from specified legal arbitrary-action and category-centroid explanations, and its selected carriers predict natural counterfactual interventions on native multi-step computations. The claim is restricted to the tested tasks, intervention family, and competing explanations.

This is an objective to test, not a conclusion available from the frozen results. A finite lookup table can reproduce every behavior on a finite exhaustive task; the proposed controls cannot rule out all conceivable category-code implementations. The study should identify which narrower explanations its evidence excludes, and avoid upgrading an accurate abstraction into a unique internal algorithm.

The minimal useful package has three connected parts: **calibrate the existing diagnostics on known counterexamples; test cross-fitted category and legal-action controls on genuinely new evaluation families; and validate prospective native-use predictions on two competent pretrained models, including a non-Abelian behavioral task**. More model sizes should follow these tests, rather than substitute for them.

## 3. Separate the questions before selecting experiments

| Question | Required new evidence | What would still be unsupported |
|---|---|---|
| Does a fixed activation set support approximate actions? | Accurate held-out transport plus algebra tests, with explicit metric, rank, regularization, and information controls. | Semantic selectivity or native use. |
| Is the semantic registration special relative to specified category explanations? | Semantic versus legal arbitrary-action refits; cross-fitted centroid/residual controls; lexical/context-family holdouts; low-rank and retained-information diagnostics. | Rejection of arbitrary unrestricted lookup mechanisms. |
| Is this carrier relevant to a native task? | Prospective counterfactual predictions, natural donor interventions, selective effects, and component/consumer checks on the task as actually run. | A unique algorithm, or necessity under all possible compensating pathways. |
| Do learned action operators add practical value? | Better held-out behavioral outcomes or fidelity/cost tradeoffs than equally informed strong centroid, local-field, and direct-map alternatives. | A positive conclusion merely because random/identity controls fail. |
| Is the proposed abstraction the internal mechanism? | Competing causal models that disagree on held-out interventions, and targeted component evidence favoring one within its stated assumptions. | Mechanism uniqueness when all tested models make the same predictions. |

Do not move from one row to the next by changing terminology. In particular, an externally multiplied sequence of fitted matrices followed by one late patch tests an intervention interface. It does not test whether the transformer itself executed those matrices in that order.

## 4. Minimum decisive package

### M0. Calibrate the diagnostics before allocating new model compute

Use cached activations where available; otherwise identify the missing small artifacts before rerunning extraction. Preserve frozen results and write new analysis outputs to a separate experiment namespace.

1. **Stable category plus context construction.** Generate a centered full-rank category code with an independent context component and a consistent group action on category coordinates. Evaluate exactly the same equivariance, relation, generator-word, permutation, and scramble statistics used on LLMs. Include a version with zero action-relevant context residual and a version with known nontrivial residual transport. These are disclosed positive/negative controls for particular claims, not simulated “LLM findings.”
2. **Legally consistent arbitrary-action refits.** For each predeclared global state permutation \(\pi\), construct \(g_\pi=\pi^{-1}g\pi\), and refit every method on the induced paired examples with the same training/validation/test division. The same permutation must hold across contexts. This preserves the full group law. Retain the old inconsistent-label and per-template scramble controls as different tests; do not rename them as this stronger control.
3. **Rank and prediction calibration.** Repeat over a small frozen dimension/regularization grid, with identity fixed versus learned as a disclosed choice. Include ranks below and at the centered category bound \(n-1\). At full category rank, arbitrary finite permutations can become exactly linear: failure to distinguish them is an expected calibration result. Compare validation-selected prediction/complexity frontiers and operator norms; do not use test errors to choose matched nulls after seeing the result.
4. **Cross-fitted centroid transport.** Estimate train-only category means \(\hat\mu_i\), and compare
   \[
   T_g^{\rm cent}(z,i)=z-\hat\mu_i+\hat\mu_{g(i)}
   \]
   with the learned operator in the *same* coordinates and with the *same* preserved complement. Report full-space versions separately. Run both an oracle-source version and a deployable version using a source decoder fit only on training data; include decoder error. This baseline is already present in stronger behavioral form in the archive and needs matched structural evaluation, not rediscovery.
5. **Residual test.** Evaluate prediction of \(z_{g(i),c}-\hat\mu_{g(i)}\), rather than allowing between-category means to dominate every score. Compare the learned map with preserved source residual, context-only predictors, and an appropriately regularized local model. A residual advantage alone still need not be semantic or causal; it is one diagnostic in the package. Do not divide by a nearly zero residual norm without reporting target energy and an absolute-error sensitivity analysis.

For a correctly updated source state, centroid increments telescope along every word. Therefore good composition or noncommutative order effects are not sufficient to beat this explanation. Also, a complete balanced orbit has zero global mean displacement for every permutation action; the global additive vector remains a weak control by construction.

**M0 stop decision:** If all apparent advantages disappear under legal-action or centroid controls, stop expanding the positive semantic-mechanism claim. Complete the negative/calibration study and identify whether a focused diagnostic paper has a substantive empirical result. Do not spend a large budget reproducing the same ambiguous finding on more checkpoints.

### M1. Collect genuinely new evaluation families

Keep the existing C7 weekday experiment as a frozen anchor. The minimal new behavioral study should have one familiar cyclic domain and one well-defined non-Abelian action, tested on two competent pretrained models from different families. Model choice follows a clean behavioral pilot, not an assumption that the smallest archived model can solve the new task.

**Cyclic anchor:** use real state-plus-operation questions with native answers, several task formulations, aliases/descriptions of states, and independent scenario variables. A new split of the same forty superficial templates is not a new family. Hold out entire construction families such as narrative scheduling versus direct arithmetic, complete paraphrase/alias families, and selected action words. An unseen alias of a known abstract state is lexical transfer; do not call it unseen-state transfer.

**Non-Abelian task:** prefer a square bearing an asymmetric marked pattern, with four rotations and a reflection, or an equivalent orientation task with an exact simulator. Use a free eight-state orbit if feasible, so different group elements have distinct effects on every full pose. The old four-corner D4 action is globally faithful, but individual corners have stabilizers and different words can agree on one corner. Check effects on the entire state or explicitly restrict to examples where the candidate words predict different answers.

For the pose task, fix the viewing convention, rotation direction, reflection axis, active/passive convention, and word order in a public truth-table generator before collecting activations. Include several asymmetric objects or descriptions; hold out objects and lexical encodings as families. Score the complete structured answer, not whichever first token happens to distinguish a subset. If clean models cannot solve the task, report that feasibility limit and use the pilot to select a simpler competent task before sealing a new confirmatory test.

**Rebinding condition:** assign symbols to semantic states afresh per independently generated scenario, with sufficient in-context evidence. Split by complete mappings/scenarios; prohibit token reuse from revealing test targets. Remove verbatim-copy, commutative-copy, and identity shortcuts when the claimed computation requires composition. This condition tests a fixed-token explanation. A context-sensitive category code remains a live alternative, and the task idea itself overlaps Todd et al.

**Sham conditions:** preserve entities, lengths, and nuisance distributions while asking for a list item, the initial state, or a transformation-independent attribute. Include a condition with the same concept co-occurrence but no target computation. Such tasks are necessary specificity checks; Arora et al. already studies closely related controls. Do not claim that observing their dissociation is automatically a new discovery.

Keep all states and action variants of one generated scenario in a single split. Fit PCA, centroids, decoders, subspaces, layer choices, and hyperparameters only on construction/development data. The confirmatory set must be newly generated or sealed after the protocol is fixed, with its origin and any human edits recorded. No manually chosen “clean examples” after inspecting the intervention results.

### M2. Test the model's computation with prospective counterfactuals

First write a high-level causal model with explicit variables: initial state \(S_0\), operations \(G_1,\ldots,G_k\), intermediate states \(S_j\), nuisance context \(C\), and answer \(Y\). Specify the candidate network sites, alignment function, allowed interventions, and prediction for every edit. Where different causal explanations agree on all chosen edits, the experiment cannot choose between them.

Use four intervention families on the sealed native tasks:

1. **Natural donor interchange.** Pair prompts differing in one relevant variable while preserving downstream instructions and nuisance context as closely as possible. At a preselected site, interchange the candidate state subspace and predict the recipient's answer from the high-level counterfactual. Include same-state/different-context and wrong-state/same-context donors. Compare learned-action edits with centroid transport, directly observed natural donors, and capacity-matched subspaces. Treat a projected donor hybrid as a hybrid; even an activation drawn from a real prompt does not guarantee its recombination with another residual is on the natural support.
2. **State-by-operation interchange.** Separately interchange candidate state and operation variables, then test their joint recombination on held-out state/operation pairs. Its target is the recipient computation with the specified donor variable substituted, not the donor's final answer. Include donors with the same final answer but different state/operation decompositions, and donors whose own answer differs from the recombined target. This makes simple answer transplantation detectable. Prefer naturally sourced changes and component-supported alignments; if optimizing an alignment, separate its training from testing and include capacity-matched irrelevant-label alignments. Successful finite-variable recombination supports the specified abstraction, while a lookup implementation may remain compatible with it.
3. **Intermediate consumer check.** For a multi-step prompt, alter a proposed intermediate state while preserving the remaining operations. The target is the changed final answer predicted by applying those *remaining* operations. Include noncommuting operation orders for which the full predicted outcomes differ. Use a naturally realizable counterpart prompt to establish the relevant answer and downstream activation distribution. A final-answer patch is a useful positive control, but cannot replace this test.
4. **Pathway and specificity checks.** On a development subset, find components that read/write the candidate carrier using natural activation changes and a small set of predeclared localization methods. Freeze the candidate set, then test it on new scenarios. Compare natural-mean/resample/freeze interventions with matched random component sets and unrelated tasks; measure relevant downstream carriers as well as answers. Include restoration from a natural donor when meaningful. A damage-and-rescue pattern strengthens a pathway account but does not by itself establish a unique or universally necessary mechanism.

Compare at least these explanations explicitly: category/centroid transport; independently fitted direct maps; generator-based action maps; a regularized state-conditioned/local displacement model; and a task-appropriate arithmetic or symbolic alternative. For cyclic tasks, concept-specific rotation and lifted integer addition can be observationally equivalent at the final answer. Differentiation requires intermediate measurements and consumers/interventions where their specified models disagree, as opposed to declaring different names for the same counterfactual table. For D4, a group-theoretic abstraction and an arithmetic normal-form algorithm may also agree completely; distinguish the abstraction from its implementation.

Report actual finite effects over a small dose grid fixed on development data. Where feasible, compare directional-derivative predictions with realized small edits as a diagnostic, then test the finite action at its intended scale. Use identical intervention sites, subspace masks, complement preservation, and allowed information across competing methods. Show edit norms and collateral effects; a post hoc norm normalization can conceal different nonlinear dose regimes.

**Primary behavioral endpoints:** complete-answer exact accuracy and a predeclared target-versus-alternative sequence log-probability margin, with all candidate tokens scored. Include natural unedited competence, target consistency under interchange, and preservation of unrelated outputs. For single-token tasks, raw logit margins remain useful. Report full-vocabulary outcomes or an explicit “other” category; renormalizing only over the desired states can hide degeneration. Avoid primary recovery ratios with small clean-corrupt denominators.

**Minimum claim gate:** native-use evidence must survive strong informed baselines, held-out scenarios, and specificity checks. If only a late edited representation works, the supported result is a controllable interface. If centroid and action operators work equally well, report that equivalence instead of claiming that algebraic structure supplied additional explanatory power.

### M3. Validate the diagnostic on held-out intervention effects

The most distinctive linkage is prospective: freeze a structural selection rule on construction data, then ask whether it predicts counterfactual fidelity on unseen scenarios and intervention families. Compare it with simple alternatives such as one-step reconstruction, category separability, retained target variance, operator norm, and edit magnitude. Fix the comparison and primary loss before scoring the sealed set.

Do not claim extra predictive value from regressing many correlated layer cells and calling them independent samples. With only two models, model generalization is case replication. Evaluate prediction of intervention outcomes within independently generated scenario blocks, and show results separately for each model/domain. If structural scores add no held-out value beyond one-step error and the centroid controls, that negative result is directly relevant to the identification question.

The primary result should be one compact comparison: which candidate explanation predicts the *same* held-out native counterfactuals most accurately, under matched information and interventions. Reconstruction and homomorphism plots then explain that result instead of standing in for it.

## 6. Statistics, decisions, and outcome branches

Declare a small family of confirmatory contrasts, their direction, minimum scientifically meaningful margins, and an inconclusive region before evaluation. Choose margins from the task's utility and pilot precision requirements, not to preserve an attractive result. Pilot samples, layer searches, and failed designs remain explicitly exploratory and separate from the sealed test.

The independent sampling unit is the generated scenario/mapping family, containing its related states, words, donors, and repeated edits. Use paired within-scenario contrasts and cluster-aware uncertainty. If lexical families and prompt families are crossed, use a justified multiway strategy or design independent outer scenario blocks; do not bootstrap overlapping prompts as independent. Keep pretrained models and layers as fixed named conditions unless a defensible model-sampling population is specified. Multiple split seeds on the same templates do not multiply the sample size.

For fixed finite domains, show exhaustive state/action summaries and uncertainty over the declared scenario distribution. Report subgroup failures, including wraparound, reflection, word order, multi-token answers, and context changes. Apply multiplicity control to the actual confirmatory family; retain all planned contrasts, including negative ones. If adaptive sampling or optional stopping is essential, its confidence guarantees must respect the block structure and score assumptions, rather than being pasted onto dependent prompt rows.

|---|---|---|
| Legal arbitrary-action and centroid controls match the original structural evidence | The old evidence is compatible with structured category transport and/or capacity effects. | Write a calibrated limitation/diagnostic study if the empirical scope and reusable benchmark justify it; do not claim recovered semantics. |

| Late patches work; intermediate/pathway tests do not | A useful control interface exists, with unresolved native use. | Compare practical utility with strong alternatives and state the limitation. |
| Carrier interventions work, but centroid/local models match action operators | The carrier is useful; group-operator recovery has not shown added explanatory or practical value. | Report the equivalence and reconsider the main contribution. |
| Structural calibration, OOD selectivity, and prospective native counterfactual prediction all succeed against specified alternatives | Evidence supports a bounded action-sensitive representation/abstraction with functional relevance. | Build the submission around this exact result, its failure cases, and the preregistered falsifiers; test one independent replication. |
| New native tasks have poor clean competence or unstable tokenization/scoring | The intervention experiment lacks a usable base behavior. | Revise feasibility with a fresh exploratory pilot and reserve new sealed data; do not interpret patch failure as absence of a mechanism. |
| Precise intervals rule out a useful advantage, or remain too wide | A negative or inconclusive result. | Preserve it, separate these cases, and make any expansion a new protocol. |

No outcome branch guarantees ICML acceptance. The positive package strengthens scientific differentiation; the negative branches prevent an expensive expansion of an unsupported claim. The key deliverable is a reproducible test whose conclusions change when its falsifiers succeed.

## 7. Required outputs before any main GPU run

The next protocol should contain: a claim/assumption/falsifier table; exact task simulators and action conventions; scenario-level split IDs; baseline information and parameter budgets; development-only selection rules; complete-answer metrics; intervention masks and dose rules; primary contrasts and independent resampling units; synthetic-control expected behavior; clean-competence gates; and an outcome-branch policy. Preserve original frozen artifacts and record every new experiment separately, including failed and inconclusive runs.

The resulting study should allow a skeptical reader to answer three concrete questions: **Could this score be obtained by a legal arbitrary action on a category code? Could a simpler equally informed transport baseline do the same job? Does the claimed carrier predict what happens when the model itself continues a changed computation?** The new work is valuable only to the extent that its experiments resolve these questions more sharply than the existing literature and frozen runs.

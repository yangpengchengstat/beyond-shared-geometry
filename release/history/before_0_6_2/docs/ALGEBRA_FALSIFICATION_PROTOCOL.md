# Algebra Falsification Suite Protocol

Status: **FROZEN BEFORE GPU EXECUTION**. This experiment family is isolated from and does not alter `main_full_003` or paper v5.

## Question and logic

AFS tests the reviewer alternative that coherent orbit geometry alone makes separately fitted maps look compositional. The logical graph is:

```text
pretrained activation geometry -> fitted linear maps -> apparent composition
              |                         |
              |                         +-- B: break label/table registration
              +-- C: preserve points, break template correspondence

generator training only -> never-fitted composites (A, primary)
embedding hidden state 0 -> lexical/architectural diagnostic (D)
```

`H_algebra` predicts transfer from minimal generators and specificity to the correct multiplication registration and cross-template correspondence. `H_orbit` predicts that these controls retain much of the effect.

## Frozen panel

The panel is the exact six immutable revisions in `configs/algebra_falsification.yaml`, groups C7/D4, normalized depths 0.20/0.40/0.60/0.80, latent dimension 16, split seeds 101/303/909/2701/4243, and 28/6/6 train/validation/test templates. PCA and direct operators for A/B/C are imported read-only from `main_full_003`. Bootstrap uses 5,000 replicates and seed 314159 in FULL. All intervals are two-sided 95% percentile intervals.

The hierarchy for paired bootstrap inference is `model -> depth -> split -> template`. Models are a fixed robustness panel; model-specific results are reported separately. Pooled summaries describe the panel and do not turn six models into a population sample. Permutation draws and scramble seeds are control randomness, not scientific model/split replication.

## A: Generator-only generalization

The row-vector convention is used throughout. C7 fits only `R(r)` on TRAIN one-step pairs. It predicts `r^k` as `R(r)^k` for `k=2,...,6`; `k=7` is reported separately as an identity-cycle diagnostic. D4 fits only `R(r)` and `R(s)`. Canonical shortest words are generated by breadth-first search through `bsg.groups.d4.row_word_product`; no D4 product is hand-coded. The exact never-fitted canonical elements are `r^2`, `r^3`, `rs`, `sr`, and `r^2s`. The requested notation `r^3s` resolves to the same D4 element as `sr` under this row convention, so it is not double-counted as an independent target. The repository convention makes `s @ r @ s = r^-1`.

For a held-out template and composite `g`, the primary metric is

```text
E_gen_eq(g) = ||Z R_hat(w(g)) - Z_g||_F^2 / (||Z_g||_F^2 + eps).
```

The generator generalization gap is `E_gen_eq - E_direct_ridge_eq`. Comparators are direct independent Ridge, identity, one matched random orthogonal generator (or generator pair) whose powers/words are reused, and for D4 a deterministic same-length wrong word resolving to a different element. Generator fitting never receives composite pairs. D4 relation diagnostics `r^4=I`, `s^2=I`, and `srs=r^-1` are secondary and are not substituted for held-out state prediction.

Primary paired contrasts are generator minus identity, matched random, and direct Ridge; D4 additionally uses correct word minus matched wrong word. Lower is better.

## B: Algebra-registration permutation null

Activations, PCA coordinates, and independent operators remain byte-for-byte fixed. Identity-preserving permutations relabel only nonidentity operators, while the original multiplication table remains fixed. A permutation is excluded exactly when it preserves every product in the canonical table. This yields 6 C7 and 8 D4 automorphisms. FULL draws exactly 5,000 non-automorphic permutations per cell using master seed 8675309 and a deterministic cell hash. Sampling is with replacement: C7 has only 714 distinct admissible permutations, so 5,000 unique draws are impossible.

The frozen sampling is with replacement. Both operator-space and data-supported group-law defects (`E_hom_op` and `E_hom_data`) are computed. Per cell:

```text
p_lower = (1 + count(null_defect <= true_defect)) / (N + 1)
separation = (null_mean - true_defect) / null_sd
```

The output also reports null mean, median, 2.5/97.5 percentiles, and the true lower-tail percentile. Permutations are a conditional randomization distribution, not independent scientific replicates.

## C: Correspondence scrambling

Both nulls reuse the exact primary PCA basis and latent vectors. They preserve template membership, counts, dimension, and each template's vector multiset. Only TRAIN correspondences are changed; validation/test targets remain true semantic targets.

- **C1 `train_only_state_relabel`:** each training template receives an independent nontrivial state permutation. Within that template, both pair endpoints are relabeled as `(pi_t(s), pi_t(gs))`. Permutations that leave the registered action unchanged are rejected. This preserves a coherent local orbit but destroys a shared registration across templates.
- **C2 `template_independent_target_scramble`:** independently for every training template and nonidentity element, the target correspondence is permuted while the source index remains true. Identity stays identity. This preserves source/target vector multisets per template and element but more aggressively destroys action consistency.

Each variant uses seeds 70001, 70003, 70009, 70019, and 70039. Ridge is fit only to scrambled TRAIN pairs and evaluated against true held-out correspondences. Primary metrics are `E_eq` and `E_rel_data`; `E_rel_op`, composition, and inverse defects are also reported. Scramble seed is nested control randomness only.

## D: Embedding diagnostic

For the exact Llama and Qwen causal-LM architectures, the diagnostic representation is Hugging Face `hidden_states[0]`: the embedding hidden state presented before transformer block 1. The same unique target-token span is averaged as in the main experiment. Runtime checks require model types `llama` or `qwen2`, exact block counts, immutable revisions, a public input-embedding interface, and one hidden vector per canonical row. It is labeled layer 0 and is never silently treated as a block output or replicated over fake depth slots.

Independent Ridge `E_eq`, `E_rel_data`, `E_rel_op`, and generator composite prediction are reported. D has no success gate.

## Frozen gates

Gates are evaluated only for the complete FULL matrix. SMOKE and PRE_FULL return `NOT_EVALUABLE` for scientific gates.

- **A1 C7:** a model qualifies if generator minus matched-random mean is negative at at least 3/4 depths. PASS requires at least 5/6 models qualify and the pooled panel hierarchical CI upper bound is below zero.
- **A2 D4:** a model qualifies if both generator-minus-random and correct-minus-wrong means are negative at at least 3/4 depths. PASS requires at least 5/6 models qualify and both pooled CI upper bounds are below zero.
- **B:** for both groups and both group-law metrics, true defect must be strictly below the cell null 2.5th percentile in at least 80% of cells. No architecture family may have true defect at or above the null median in 50% or more of its cells.
- **C:** separately for C1/C2 and C7/D4, real-minus-scrambled held-out `E_eq` must be negative in at least 5/6 model summaries and the pooled CI upper bound must be below zero.
- **D:** diagnostic only.

Overall: `STRONG_PASS` iff A1+A2+B+C pass; `PARTIAL_PASS` iff A1+A2 pass and exactly one or both of B/C pass; `FAIL` if A fails materially; `NOT_EVALUABLE` if the execution/statistical contract is incomplete.

## Interpretation

If A+B+C pass, the strongest allowed statement is: "Minimal generator actions learned from pretrained-model activations generalize to transformations that were never directly fitted, while geometry-preserving disruptions of algebraic registration and cross-template correspondence destroy this compositional advantage. This provides evidence that the recovered algebra is not explained by coherent orbit geometry alone."

Forbidden interpretations include claims that AFS proves exact internal groups, symbolic group computation, a unique causal mechanism, or universal semantic algebra. AFS is structural falsification evidence, not mechanism proof.

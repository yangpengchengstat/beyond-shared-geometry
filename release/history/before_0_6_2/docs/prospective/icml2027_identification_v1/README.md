# Beyond Shared Geometry: prospective identification study

Planning documents dated 16 October 2026. Start with [the integrated study plan](ICML2027_NEXT_STUDY.md).

- [Statistical and synthetic protocol](STATISTICAL_AND_SYNTHETIC_PROTOCOL.md): estimands, baselines, dependence, power, multiplicity and disclosed controls.
- [Feasibility and implementation](FEASIBILITY_AND_IMPLEMENTATION.md): verified archived inputs, train-only boundaries, exact tensor shapes and extraction contracts.
- [Native causal protocol](NATIVE_CAUSAL_PROTOCOL.md): real task behavior, counterfactuals, patch controls and consumer checks.
- [Requested prior-work references](PRIOR_WORK_REFERENCE_MAP.md): the seven requested papers and patching methodology.
- [Targeted deep search](TARGETED_DEEP_SEARCH_AND_NOVELTY.md): original-source comparisons and novelty limits.
- [Experiment matrix](experiment_matrix.json): machine-readable proposed axes and counts.
- [Evidence index](evidence/README.md): read-only metadata and finite action design tables; no model weights or activation arrays.

This folder is a proposed experiment specification, not an executed run, preregistration certificate, revised scientific result, or submission-readiness certificate. The original FULL/AFS evidence and released manuscript are preserved. Synthetic/sham work means disclosed controls; no empirical result is invented. The protocol, implementation and dataset must be finalized before confirmatory outcomes are accessed. Future outputs belong in a new run namespace.

The review used accessible project histories and audited local artifacts; it does not assert complete access to every historical conversation. Primary-source search was targeted, with pinned versions, and does not establish exhaustive coverage of the literature. Official ICML 2027 requirements remain unverified at this cutoff.

No models were loaded or downloaded, no estimator was fitted, no GPU/cloud job was launched, and no remote repository was changed for this planning delivery. A pure finite permutation enumeration and file-header/hash checks validate design/inputs only.

Version 0.5.8. Set main.tex as the main document and compile with pdfLaTeX and
BibTeX (or latexmk -pdf). The official anonymous TMLR support files are unchanged.

The manuscript reorganizes already completed evidence. All original results,
16-dimensional primary outcomes, 8/16 sensitivity and orthogonality-comparison
outcomes are retained. No numerical tests or experiments were rerun for this
revision. LOFO remains prepared and unexecuted.

The supplementary directory contains full-precision saved endpoints, explicit
input mappings and presentation-only generators. These do not rerun models,
refit PCA/operators or replace the original scientific records. This source
bundle compiles without the separately retained multi-GB result archives.
Final author review remains pending. Local compilation or packaging does not
submit the paper or upload it to Overleaf, GitHub or a journal.

Portable archives include the source-referenced revision, scientific-content,
dependency, style and compile reports under review_notes/. The working project
keeps the same reports at its root. submission_metadata.json maps both layouts.

Evidence decision after manuscript revision 0.4.7
Date: 28 October 2026
Status: recommendation only; no additional analysis or experiment executed

DECISION
No new experiment is logically required for the retained claims: the paper
states analytical results and describes the recorded fixed panels. The claims
do not assert independent-context generalization, semantic uniqueness, a native
causal mechanism, or empirical certification by Theorem 8.

For a stronger ICML submission, a focused independent-context evaluation is the
most useful potential additional experiment. It is recommended if robustness
beyond the present context construction is made a core empirical claim. It is
not a guarantee of acceptance. More model counts, another calibration sweep,
or a full historical rerun are not the recommended next step.

FIRST: CHECK WHETHER EXISTING COORDINATES CAN CONNECT THEORY AND EVIDENCE
Perform a read-only inventory before committing to computation. Required inputs
for each model/readout/domain are complete paired context-state coordinates,
model revision, frozen PCA/centering identity, state ordering, exact action table,
context/family IDs, split roles and original archive hashes. Summary CSVs are
insufficient. Different PCA frames cannot be pooled merely because all have
16 columns. Nominal 48-cell coverage must be verified, not assumed.

If these inputs are available, a separately authorized and frozen retrospective
finite-bank analysis could compute eta, the real-type budget gamma and the
Theorem 7 risk bounds. Its contract should include:
- One explicitly chosen already-observed evaluation bank per coordinate cell;
  no automatic merge of training, validation, pilot, support or reserved rows.
- Uniform complete states and actions, including identity and D4 fixed points.
  This differs from the original changed-state prediction endpoint.
- A new empirical second-moment metric, disclosed as such. Original PCA and
  predictors remain unchanged. The full target bank is observed.
- Fixed rank 16, numerical precision and absolute/relative residual rules,
  rank threshold, conditioning report, type-pairing checks and logged handling
  of roundoff. Failure gives not_evaluable, not silent jitter or rank reduction.
- Known group/type projectors, not type guesses from fitted Ridge matrices.
  For the specified four-corner D4 action, the two unsupported one-dimensional
  types must have zero energy up to the declared numerical tolerance.
- Every valid or failed cell, not favorable layers only; exact input provenance.
  Direct least-squares and spectral eta must agree within declared tolerance.
- No Theorem 8 confidence claim, bootstrap, population significance decision,
  calibration rerun, model forward or model download.

Freezing this analysis now does not make the already-inspected bank an
independent confirmation. The endpoint is a retrospective deterministic
finite-bank structural diagnostic, approximated numerically.

The natural scale matters: normalized type correction is at most 1/16 in this
r=16 C7/D4 setting. The analytical r=1 separation is not a prediction of a large
LLM effect. A zero correction does not invalidate the risk theorem. Success
means learning something interpretable about exact-action class risk that was
not apparent from the reported regression summaries, not obtaining a positive
type correction. A numerical identity passing is engineering validation rather
than a new empirical discovery. Missing inputs do not authorize recreating them
with model execution.

SECOND: WHEN AN INDEPENDENT CONTEXT EXPERIMENT IS WORTH DOING
If the intended claim remains fixed-panel characterization, it can be deferred.
If the paper claims robustness to a different context construction, independent
contexts are needed; cached spectral analysis cannot supply that evidence.

A single bounded follow-up should use an independently authored context bank,
with paired contextual variants where transport is tested, frozen before any
model outputs are inspected. Authors should not merely paraphrase the original
40 templates. Complete state blocks and family IDs must be retained. It still
tests seen state vocabularies unless new states are separately designed; it must
not be described as unseen-vocabulary or new-domain generalization.

Freeze model revisions, readouts, preprocessing, fitting/selection rules and the
primary comparison before evaluation. Prefer frozen predictors and normalization
from construction data when available. If new training is indispensable, declare
an independent training/validation portion before collecting the final test bank.
Never select layers, budgets or registrations on the new test outcomes.

One suitable primary comparison is dedicated context-difference fitting versus
applying coordinate-fitted operators to the same paired differences. Prespecified
category/coherent-registration controls can be secondary. The exact retained
scientific claim should determine this choice before execution. A common complete
source/action grid removes changed-state row mismatch, but different registrations
still define different targets; this does not establish semantic uniqueness.
Keep original historical scores separate if a new grid changes the endpoint.

Plan uncertainty at independently authored context-family level, with paired
contrasts, a declared practically meaningful effect and a fixed multiplicity
policy for any multiple primary targets. Determine sample size from an explicit
precision or power calculation with conservative assumptions, not from model x
layer x split counts or the conservative Theorem 8 precheck formula. No sample
size is committed in this unexecuted recommendation, and no additional large
synthetic calibration is proposed.

STOPPING RULE FOR RESEARCH SCOPE
Do not expand groups, dimensions, models, prompts or endpoints merely to obtain a
favorable result. Preserve negative outcomes. A failed native branch should not
be restarted solely to manufacture a positive causal component for a paper whose
retained claim concerns predictive structure.

CURRENT ACTION
Finish and review the paper-only revision. Any cached spectral analysis or new
context experiment requires its own explicit scope and output location. None was
run during revision 0.4.7.

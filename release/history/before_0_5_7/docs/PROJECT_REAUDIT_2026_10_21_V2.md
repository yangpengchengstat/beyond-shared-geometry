# Project re-audit, 21 October 2026

## Adjudication

The project now supports a reproducible, bounded empirical characterization of fitted finite actions. It does **not yet support a strong ICML main-conference submission on the basis of a novel general theory, superior steering, a uniquely identified native mechanism, or universal linear compactness**. My scientific recommendation is major revision before submission. This is an audit judgment, not a prediction of an acceptance probability or an official review.

The completed characterization improves the evidence substantially and changes the story. Full kernel fields predict held-out composites better, small retained-support fields lose near the linear storage budget, and very compact category controls explain part of C7 recovery. The manuscript should explain these differences rather than assert a general operator advantage. A transparent negative/heterogeneous result can be valuable, but the present result needs a sharper discriminating question and stronger matched competitors.

## Material scientific corrections

1. **Finite-state realization is weak evidence by itself.** Full affine rank permits any consistent state permutation. Shared context actions are more restrictive, but a stable state code plus an unchanged context component still supports them exactly. The proof now uses invariance of the left kernel `ker(Z^T)`, distinguishes rank-deficient projector identity from a coherent invertible extension, and gives explicit contextual/state-code counterexamples.
2. **Prediction and algebraic consistency are coupled.** The error-propagation argument needs pointwise errors, operator norm control and target-denominator bounds. Small average prediction loss alone is not a numerical bound on the reported normalized defect. Orthogonal coordinate changes preserve measured Euclidean defects; general invertible changes need not.
3. **Historical behavioral controls are not matched interventions.** The source-conditioned additive baseline acts in the full hidden space; operator edits preserve the PCA complement. The old mean-overwrite span hook also collapses within-span deviations and lacks a matched zero-delta sham. The D4 relation additive rows receive endpoint-conditioned edits, so equality across true/reference/wrong words is built into that control. Recorded logit effects are not full-answer accuracy or proof of native computation.
4. **Historical cross-model alignment fits test correspondences.** Procrustes uses test pairs, and intertwiners fit/evaluate the same elements. The shuffled-target control does not refit the alignment. These results are in-sample compatibility diagnostics, not held-out transfer or mechanistic equivalence.
5. **Bootstrap procedures differ.** FULL uses a base seed with analysis offsets and hierarchical resampling; matched AFS-D contrasts keep depth fixed; the global-additive study resamples overlapping split-level summaries. The manuscript now describes these separately. Historical per-target normalization differs from the new training-energy normalization; prediction and context endpoints also have different denominators.
6. **The new storage comparison is estimator-specific.** Full generator fields win in all 48 conditions but store 84 times (C7) and 36 times (D4) the generator coefficients. The small-support recipe loses in all 48. Ridge fits all target pairs; the small kernel stores only K target displacements after viewing all training source inputs. Retained-coordinate matching does not equalize target exposure, statistical capacity, training memory or model/PCA overhead.
7. **Category controls materially narrow C7 claims.** Direct decoded-centroid prediction uses 112 coordinates plus a known action table, with mean loss 0.012013 versus ridge 0.014900 and 1792 matrix coordinates. It wins only 9/24 cells; model means split by the two fixed lineages. D4 is worse on average (0.062349 versus 0.041349). Perfect clean decoding does not prove correct re-decoding of an edited intermediate state. One decode followed by a known composite lookup is not learned primitive composition.
8. **S3 and context effects require restraint.** C7 context gain has lower sensitivity endpoint 0.009997, below the old 0.01 margin. The S3 joint context interval spans zero, and identity is already competitive on prediction. Its support method receives extra data; its potential optimization is conditional on archived results. New entity names/triples are held out in the appropriate S3 strata even though abstract assignment states are seen.

All ten original characterization contrasts are reported in the appendix. Original `paper_eligible=false`, disabled formal inference, prior failures and original frozen files remain unchanged. `release/characterization_review.json` records the authorized **manual descriptive integration**, its input hashes and limits. It is not automatic promotion or human scientific signoff.

## Literature and peer-method consequences

The [primary-source re-audit](LITERATURE_REAUDIT_2026_10_21.md) records inspected versions and relevant sections for Lenc–Vedaldi, Chughtai, Engels, Nanda, Yuan Sun, Wu, Alan Sun–Toneva, Arora, Wurgaft and Hu. It is a targeted reread, not exhaustive search or external experimental reproduction.

The central novelty risk is direct precedent for transformation compatibility, local/global realizations, composition and error accumulation. Peer comparison also needs faithful information accounting: Engels mean-ablates complementary components; Wurgaft's manifold and straight-line arms overwrite different spaces; Arora's full factorial decomposition exceeds a centroid adaptation; Hu requires source-model test displacements. Existing structural results do not establish superiority to any of those published behavioral methods.

## Engineering changes and compatibility

- Import validation now accepts only the exact historical S3 development bank containing 9,216 reserved cross-block rows per model. It does not exempt arbitrary reserved data, new test data or reordered/modified identities.
- Confirmation extraction requires a run-bound freeze, matching configuration, dataset seal, completed gate/power evidence and verified development cache **before runtime creation**. A bare JSON with family/orbit counts is rejected.
- Completed stages store output hash receipts and verify them before resume. Missing/modified outputs or old complete markers without receipts fail closed; they are not silently regenerated. Later additions to a shared native output directory do not invalidate earlier intact artifacts.
- Native feature assembly rejects duplicate, negative, fractional or out-of-range row indices, inconsistent dimensions and nonfinite features.
- Historical and new descriptive asset builders have separate ownership. Rebuilding historical figures cannot relabel reviewed characterization provenance. Curated input hashes, paths and original eligibility flags are validated before rendering.
- A generated TeX caption's accidental control character was corrected. Updated tables, figures, manuscript and packages are regenerated from the declared inputs.

The active runtime version is 0.3.2. Previous engineering manifests are retained under `release/history/`. Historical `src/bsg`, frozen configurations and the characterization worker remain unchanged. New output receipts intentionally make old pipeline state incompatible with automatic 0.3.2 resume. Do not replace code underneath a running Pod or use this release to force continuation of an old failed study. Runtime hardening is an engineering correction; it does not retroactively prove that an old execution was invalid or change its result.

Actual verification counts and PDF/package checks are recorded in `release/validation_summary.json`, `release/pdf_qa.json` and the audit's private test logs. Optional Torch/Transformers tests cannot establish GPU behavior when skipped. A source-only pass is not a model replication.

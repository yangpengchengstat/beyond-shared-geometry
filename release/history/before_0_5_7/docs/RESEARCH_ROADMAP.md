## 1. Distinguish recovery from stable state coding

Use the saved train-only PCA coordinates to fit state-centroid replacement with the context residual retained. Compare this predictor and residual-only operators against the learned operators on the same held-out templates and actual targets. The existing FULL source-conditioned additive behavioral baseline is already a strong related comparator; it should be extended under matched PCA and structural metrics rather than described as missing.

Construct consistently registered alternative actions on the same state vocabulary and refit the same operator class. Preserve capacity, train/test partitions, and information supplied to each estimator. AFS-B's operator relabeling and AFS-C's inconsistent correspondence scrambles do not perform this test. A single conjugation of every state/action may also be only a coordinate relabeling; explain exactly which semantic correspondence is changed and what difference the null can identify.

Match direct prediction errors, operator norms, and effective ranks before interpreting excess composition fidelity. Scan ridge strength prospectively and report sensitivity rather than selecting it for a preferred algebraic outcome. The existing dimension sensitivity covers only the recorded subset; it is not a ridge sweep.

## 2. Strengthen generalization and uncertainty

Hold out genuine template families, lexical realizations, or semantic domains, rather than new partitions of the same short templates. A third qualitatively different action could test breadth after the main alternative explanations are addressed. Adding more cyclic labels or models alone does not settle semantic specificity.

Keep historical intervals and add a sensitivity analysis that respects shared templates, repeated splits, layers within models, and shared model-pair endpoints. State whether inference concerns a fixed panel, template sampling, split variation, or a broader population. Additional bootstrap draws do not add independent data sources.

## 3. Test mechanisms and cross-model transfer

Use an explicit high-level causal model and intervention distribution. Evaluate actual target predictions, accuracy, necessity/mediation, and suitable sham patches, with source-conditioned additive and residual-preserving alternatives. External multiplication followed by one activation patch must remain distinct from a model's native sequential computation. Manifold steering becomes a direct baseline only if steering efficacy is made a central claim.

For cross-model maps, report singular values, effective rank, condition number, and coverage of nontrivial components. Evaluate held-out elements/constraints and predictive activation transport; refit each null with matched freedom. A low homogeneous commutation residual alone is insufficient.

## 4. Avoid invalid or redundant upgrades

- A held-out multiplication-pair evaluation is useful only if it removes actual fitting or selection information. Independent ridge already has no pairwise relation loss; merely withholding an unused relation does not create a new training holdout.
- Same group order does not imply matched actions. D4 has eight elements but acts here on four corners. A faithful C8 action on those same four labels is impossible. Any competing-algebra test must state faithfulness, stabilizers, action capacity, and endpoint aliasing; imposing an inconsistent table is not a learnable alternative action.
- Do not equate data-space and operator-space numbers: the preserved metrics have different norms and aggregands. Any normalized comparison must be introduced as a new derived analysis.
- SVD, local tangent-space estimation, curvature, continuous groups, and untrained-model controls were discussed historically. They are not completed experiments merely because a plan or pedagogical note exists.
- The finite-orbit existence proof, change-of-basis identities, and error propagation do not independently establish a new mathematical theory. Use them to design interpretable tests.

The current release supports the narrower recoverability claim without these prospective experiments. The stronger claims require new evidence, and their priority follows the scientific question rather than a target reference count or number of benchmarks.

MAIN28 manuscript revision 0.4.7
Date: 28 October 2026
Baseline: reviewed publication 0.4.6
Scientific runtime: 0.4.0, unchanged

PURPOSE
Make the existing analytical and empirical contributions easier to evaluate.
This is a manuscript and presentation revision. It does not implement the
proposed finite-bank spectral analysis or authorize any new experiment.

CHANGES
1. The abstract and introduction lead with a theoretical distinction and three
   completed empirical findings, without claiming that the theoretical quantity
   has already explained the LLM measurements.
2. Standard finite-orbit, propagation and additive-cancellation statements move
   intact to Appendix A; concise main-text consequences replace their formal
   presentation. Main Section 3 now introduces the fixed-group r=1 example: identical optimal
   unconstrained regression risk and untyped orbit spectrum, but different
   exact-action risks. It then defines the exact orthogonal-action target and
   states the existing Theorem 7 bound with its factor-two implication.
3. Main Table 1 presents three findings. The original six-row evidence table is
   retained unchanged in the replay appendix, with all its numerical values,
   information conditions, masks and normalization distinctions.
4. Main Figure 1 plots all five already recorded budgets for limited-support,
   RFF and Nystrom predictors, plus the ridge reference, in C7 and D4. Inputs are
   existing scalar means in the reviewed derived_summary.json. There is no
   statistical recomputation, fitted scaling curve, uncertainty band or budget
   selection. The CSV and source record retain exact values and input hashes.
5. Appendix B adds an elementary scale observation: for C7/D4 the real types
   have dimensions 1 or 2, so the normalized type-budget correction is at most
   1/r (1/16 at r=16). This is not an empirical result or a new principal theorem.
   The four-corner D4 support decomposition is an analytical check for possible
   future implementation, not a check claimed to have run on LLM coordinates.
6. The conservative finite-context certificate stays in the appendix. The old
   panel is not certified, and its necessary precheck sample counts are not an
   experimental size recommendation. Standard tools retain their citations.
7. AFS-B remains a restricted-reference separation score; cross-registration
   comparisons retain distinct target tasks and registration-specific masks.
8. Discussion separates a possible retrospective cached spectral diagnostic
   from a genuinely independent context evaluation. Neither has been performed.

UNCHANGED
All numerical experiment sources, configurations, studies, tests, results,
original generated numerical tables and original figure files are unchanged.
No eligibility flag, failed scientific gate, calibration record or model pin is
rewritten. The entire parent 0.4.6 directory remains separate and unchanged.
Original archives and all other earlier releases are untouched.

SCOPE OF VALIDATION
Publication checks cover input hashes, derivative provenance, manuscript
references, source preservation, PDF compilation/layout and portable packages.
Inherited model-free software tests check existing software behavior. These are
not new research experiments or statistical calibration. No supplied report's
claimed implementation checks are adopted as verified project results.

PUBLICATION STATUS
The theoretical counterexample and risk result are stronger as a narrative,
but this revision adds no independent scientific evidence. It does not by itself
warrant upgrading an ICML assessment to an acceptance recommendation. A new
finite-bank analysis would need a separate reviewed protocol and actual outputs;
a new-context claim would need genuinely independent context evidence.
